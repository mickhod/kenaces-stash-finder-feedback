# Kenace’s Stash Finder — Feedback

Use this repository to [report a bug](https://github.com/mickhod/kenaces-stash-finder-feedback/issues/new) or [suggest an improvement](https://github.com/mickhod/kenaces-stash-finder-feedback/issues/new).

Before opening an issue, please check the existing issues to see whether someone has already reported the same problem.

## About the mod

Kenace’s Stash Finder is a client-side Fabric mod for finding and organizing items in storage you have opened. It can search saved storage nearby, highlight containers containing a selected item, search inside open containers, and sort supported containers.

The mod supports chests, barrels, shulker boxes, hoppers, dispensers, droppers, furnaces, and brewing stands. Search can distinguish custom item variants, including custom player heads, when their contents have been scanned.

The mod only records a container after you open it. Changes made while it is closed won’t appear until you open it again. It runs on the client; the server does not need to install it.

## Requirements

- Minecraft Java Edition **26.1.2**
- Fabric Loader **0.19.5 or newer**
- Fabric API for Minecraft 26.1.2
- Mod Menu **18.0.2 or newer**
- Java **25 or newer**

## Reporting a bug

Please include as much of the following as you can:

- What you expected to happen and what happened instead.
- Steps to reproduce the issue.
- Your mod version, Minecraft version, and Fabric Loader version.
- Whether you were in single-player or on a server.
- Screenshots or a relevant section of `latest.log`, if available.

Please remove account details, server addresses, and other private information before posting logs or screenshots.

## Suggesting an improvement

Describe what you’d like the mod to do and how it would help. If possible, include an example of how you would use the feature.
